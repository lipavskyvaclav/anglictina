Tahák: 2. stupeň přídavných jmen

1. Krátká slova: přidáme -er

clean → cleaner
hot → hotter
easy → easier
thin → thinner

2. Dlouhá slova: more + slovo

more interesting more dangerous more modern

3. Nepravidelná slova (úplně jiné slovo)

good → better (lepší)
bad → worse (horší)

4. Porovnání: than (= než)

Píšeme vždy za 2. stupněm: smaller than, more modern than.
